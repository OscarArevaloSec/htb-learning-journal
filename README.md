# HTB Learning Journal

This repository contains sanitized notes from my Hack The Box learning journey. The purpose is to document methodology, tools, lessons learned, and defensive takeaways without publishing flags, restricted walkthroughs, proprietary content, active-machine solutions, credentials, or sensitive lab artifacts.

## Repository Structure

| Folder | Purpose |
|---|---|
| `methodology/` | General methodology notes that do not reveal active-machine solutions. |
| `tools/` | Tool reference notes focused on what the tool does and what defenders can learn from it. |
| `modules/` | Sanitized module reflections and key takeaways. |
| `reflections/` | Personal learning reflections and growth notes. |
| `CJCA_JUNE_23_RECOVERY_RUNBOOK.md` | June 23 CJCA recovery schedule, go/no-go standards, and execution rules. |

## Content Policy

| Rule | Reason |
|---|---|
| No flags, tokens, or challenge answers | Protects platform integrity and keeps the repository professional. |
| No full walkthroughs for active or restricted machines | Avoids violating platform rules and keeps focus on learning. |
| No proprietary course text copied verbatim | Keeps the repository original and ethical. |
| No credentials, target IPs, or sensitive artifacts | Prevents accidental disclosure. |
| Defensive takeaway required | Connects offensive learning to blue-team value. |
