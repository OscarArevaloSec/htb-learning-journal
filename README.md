# HTB Learning Journal

Sanitized notes from my Hack The Box certification journey. This repository documents methodology, tools, and lessons learned — not flags, not active-machine walkthroughs, not prohibited content.

## Structure

```
methodology/    — General penetration testing methodology notes
tools/          — Tool reference guides and usage examples
modules/        — Sanitized module reflections and key takeaways
reflections/    — Personal learning reflections and growth notes
```

## Content Policy

Before any content is pushed to this repository, it is reviewed against the following checklist:

- No flags or tokens
- No full walkthroughs for active or recently retired machines
- No proprietary HTB course content reproduced verbatim
- No credentials, target IPs, or sensitive lab artifacts
- No content that violates HTB's Terms of Service

## Purpose

This journal serves as a professional record of my offensive security learning. The goal is not to document exploits — it is to document **how I think**, **what I learned**, and **how it applies to real-world security operations**.
