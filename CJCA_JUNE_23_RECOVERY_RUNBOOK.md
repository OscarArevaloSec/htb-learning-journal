# CJCA June 23 Recovery Runbook

This runbook supports the **June 23, 2026 CJCA target date**. The goal is not to collect more resources. The goal is to produce exam-like evidence, findings, and reports under time pressure.

## Operating Rule

Until the CJCA exam is complete, do not create new repositories, scripts, or templates unless a hands-on practice task proves that the missing asset is blocking execution. The default action is to use the existing report template, evidence log, and assessment checklists.

| June 19 | Weak-spot remediation | Corrected evidence log or finding |
| June 20 | Go / no-go review | Written decision with reasons |
| June 21 | Final mock and report polish | Final mock report section and checklist update |
| June 22 | Light review and workspace prep | Clean workspace and verified tools |
| June 23 | Exam target date | Start only if readiness is green |

## Go / No-Go Standards

The June 23 target is reasonable only if the following items are green by June 20.

- [ ] I can enumerate a fresh target without relying on a walkthrough.
- [ ] I can document commands, screenshots, interpretations, and timestamps while working.
- [ ] I can write a complete finding with description, evidence, impact, and remediation.
- [ ] I can complete at least one Linux or Windows privilege escalation path and explain the evidence.
- [ ] I can classify security events as true positive or false positive with log evidence.
- [ ] I have completed one 3–4 hour mock cycle before June 23.

## Weekly Review Questions

After each serious study block, write short answers to the following questions in Notion or in the learning journal.

1. What took too long?
2. What did I miss during enumeration, exploitation, triage, or reporting?
3. Which checklist did I ignore under pressure?
4. What must be practiced before the next mock?

## Blunt Reminder

If most of the work becomes planning, formatting, or reorganizing notes, then the recovery plan is failing. CJCA preparation must now look like **practice, evidence capture, and report writing**.
